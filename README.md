# Tuomas Kuusisto Portfolio

This repository contains my personal portfolio site built with GitHub Pages and Jekyll.

## Live Site

https://tujokuus.github.io/

## About

The site presents my background, work experience, selected data and machine learning projects, and links to external project pages such as GitHub, Streamlit, and Kaggle.

## Tech Stack

- GitHub Pages
- Jekyll
- Markdown
- Minimal Jekyll theme

## Main Files

- `index.md` – main portfolio page content
- `_config.yml` – sidebar content, title, links, and site configuration
- `_layouts/default.html` – custom layout and image/gallery styling
- `images/` – screenshots and profile image
- `pdf/resume.pdf` – CV linked from the sidebar
